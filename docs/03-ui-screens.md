# 03. 화면별 UI 구현 지침

> 화면 4개 + 모달 3개의 **배치, 문구, 상태**를 정합니다.
> 따옴표(「」) 안 문구는 **글자 그대로** 씁니다. 색·크기는 `docs/02`의 토큰·클래스를 씁니다.

---

## 0. 공통 틀 (모든 화면)

```
┌──────────────────────────────────────────────┐
│ HONBO                  게임 선택  랭킹  [남정_01] │  ← .nav-bar (sticky)
├──────────────────────────────────────────────┤
│                                              │
│              (화면 내용: main#app)             │
│                                              │
├──────────────────────────────────────────────┤
│ 게임 선택 · 랭킹                  © 2026 HONBO │  ← .footer
│ H O N B O (거대한 외곽선 글자)                 │
└──────────────────────────────────────────────┘
```
- 닉네임이 없으면 닉네임 칩 대신 「닉네임 정하기」 링크(→ `#/`)
- 플레이 화면에서는 푸터를 숨긴다 (게임에 집중)
- 각 화면 파일(`screens/*.js`)은 `render(container, params)` 함수 하나와, 화면을 떠날 때 타이머·이벤트를 정리하는 `destroy()` 함수를 export 한다

## 1. 홈 화면 `#/` (`screens/home.js`)

### 배치
```
┌───────────── .hero (아래 모서리 --radius-jumbo 곡선) ─────────────┐
│  [NEW 배지] 혼자 하는 보드게임                                     │
│                                                                  │
│  혼자서도                                                         │
│  꽉 찬 퍼즐 한 판          ← --fs-display-xl, 2줄                 │
│                                                                  │
│  닉네임만 정하면 바로 시작해요. 울타리와 마방진을 풀고 전체 랭킹에    │
│  도전해 보세요.            ← --fs-body-lg, --color-ink-soft        │
│                                                                  │
│  닉네임                                                           │
│  [ 2~12자, 한글·영문·숫자·_            ]  [ 시작하기 ] ← .btn-green │
│  (오류 문구 자리)                                                  │
└──────────────────────────────────────────────────────────────────┘
╔══ 퍼즐 · 집중 · 기록 · 랭킹 · 혼자서도 꽉 차게 · (흐름) ══╗  ← .marquee
┌ .step-card ┐ ┌ .step-card ┐ ┌ .step-card ┐
│ 1          │ │ 2          │ │ 3          │
│ 닉네임 정하기 │ │ 게임 고르기  │ │ 랭킹 도전    │
│ 설명       │ │ 설명        │ │ 설명        │
└────────────┘ └────────────┘ └────────────┘
┌──────────────── .cta-band ────────────────┐
│ 지금 1등은 누구일까요?        [ 랭킹 보기 ] ← .btn-white │
└───────────────────────────────────────────┘
```

### 문구
| 위치 | 문구 |
|---|---|
| 배지 | 「NEW」 |
| 배지 옆 | 「혼자 하는 보드게임」 |
| 제목 | 「혼자서도」 / 「꽉 찬 퍼즐 한 판」 |
| 설명 | 「닉네임만 정하면 바로 시작해요. 울타리와 마방진을 풀고 전체 랭킹에 도전해 보세요.」 |
| 라벨 | 「닉네임」 |
| 입력 placeholder | 「2~12자, 한글·영문·숫자·_」 |
| 버튼 | 「시작하기」 (검사 중: 「확인 중…」 + 비활성) |
| 단계 1 | 「닉네임 정하기」 / 「가입 없이 이름만 정하면 끝」 |
| 단계 2 | 「게임 고르기」 / 「울타리, 마방진 중 골라서 바로 시작」 |
| 단계 3 | 「랭킹 도전」 / 「빨리 풀수록 높은 순위」 |
| CTA 띠 | 「지금 1등은 누구일까요?」 / 버튼 「랭킹 보기」 |

### 동작
1. 저장된 닉네임이 있으면 입력창에 미리 채운다.
2. 입력창에서 Enter = 「시작하기」.
3. 오류 문구 (입력창 아래 `.field-error`):
   - 비어 있음: 「닉네임을 입력해 주세요.」
   - 길이·문자 규칙 위반: 「2~12자의 한글, 영문, 숫자, _ 만 쓸 수 있어요.」
   - 부적절(Moderation 차단): 「다른 닉네임을 써 주세요.」
4. 통과하면 저장 후 `#/select`(또는 기억해 둔 원래 주소)로 이동.
5. 상세 흐름은 `docs/05` 1장.

## 2. 게임 선택 화면 `#/select` (`screens/select.js`)

### 배치 (데스크톱: 게임 카드 2열 / 768px 미만: 1열)
```
게임을 골라 주세요                              ← --fs-display-md
남정_01 님, 오늘은 어떤 퍼즐을 풀어 볼까요?       ← --color-ink-soft

┌──── .card-gradient (울타리) ────┐ ┌──── .card (마방진) ────┐
│ [인기 배지]                       │ │                        │
│ 울타리                           │ │ 마방진                  │
│ 점을 이어 하나의 울타리를 완성해요   │ │ 모든 줄의 합을 똑같이 맞춰요│
│ (작은 미리보기 그림: 3×3 예시 SVG) │ │ (작은 미리보기: 3×3 예시)  │
│ ▸ 게임 방법 (아코디언)            │ │ ▸ 게임 방법 (아코디언)    │
└──────────────────────────────────┘ └────────────────────────┘
  ↑ 카드 전체가 라디오 버튼처럼 선택됨 (선택 시 3px 흰 테두리 + 오른쪽 위 ✓)

난이도     ( 쉬움 ) ( 보통 ) ( 어려움 )            ← .chip-group
           울타리 5×5 · 마방진 3×3 처럼 선택에 맞춰 크기 안내 문구 표시
제한 시간  ( 없음 ) ( 1분 ) ( 3분 ) ( 5분 ) ( 10분 )  ← .chip-group

                 [ 게임 시작 ]                     ← .btn-green (화면의 유일한 초록)

────────── 또는 ──────────
코드로 참여
[ 예: FN-E-7K3QX9      ]  [ 참여하기 ] ← .btn-primary
(오류 문구 자리)
```

### 문구
| 위치 | 문구 |
|---|---|
| 제목 | 「게임을 골라 주세요」 |
| 부제 | 「{닉네임} 님, 오늘은 어떤 퍼즐을 풀어 볼까요?」 |
| 울타리 카드 | 제목 「울타리」, 설명 「점을 이어 하나의 울타리를 완성해요」, 배지 「인기」 |
| 마방진 카드 | 제목 「마방진」, 설명 「모든 줄의 합을 똑같이 맞춰요」 |
| 울타리 게임 방법 | 「점과 점 사이를 눌러 선을 그어요. 한 번 더 누르면 ✕(선 없음 표시), 한 번 더 누르면 지워져요.」 / 「숫자는 그 칸을 둘러싼 선의 개수예요.」 / 「모든 선이 끊기거나 갈라지지 않는 하나의 고리가 되면 성공!」 |
| 마방진 게임 방법 | 「빈칸을 고르고 숫자를 넣어요.」 / 「1부터 마지막 숫자까지 한 번씩만 쓸 수 있어요.」 / 「가로, 세로, 두 대각선의 합이 모두 목표 합과 같으면 성공!」 |
| 난이도 라벨 | 「난이도」 / 칩 「쉬움」「보통」「어려움」 |
| 크기 안내 | 울타리 선택 시 「5×5 판」「7×7 판」「10×10 판」, 마방진 선택 시 「3×3 판」「4×4 판」「5×5 판」 |
| 제한 시간 라벨 | 「제한 시간」 / 칩 「없음」「1분」「3분」「5분」「10분」 |
| 시작 버튼 | 「게임 시작」 |
| 구분 | 「또는」 |
| 코드 라벨 | 「코드로 참여」 |
| 코드 placeholder | 「예: FN-E-7K3QX9」 |
| 코드 버튼 | 「참여하기」 |
| 코드 오류 | 「코드 형식이 올바르지 않아요. 예: FN-E-7K3QX9」 |

### 기본 선택값
- 게임: 울타리 / 난이도: 쉬움 / 제한 시간: 없음
- 마지막으로 고른 값은 `localStorage`(`honbo.lastSelect`)에 저장해 다음에 미리 선택

### 동작
- 「게임 시작」 → 새 코드 생성(`docs/04` 2장) → `#/play?code={코드}&timer={초}`
- 「참여하기」 → 코드 검사 통과 시 `#/play?code={코드}&timer={선택한 초}` (게임·난이도는 코드를 따름. 화면에서 고른 게임·난이도는 무시)
- 코드 입력은 앞뒤 공백 제거 + 대문자 변환 후 검사

## 3. 게임 플레이 화면 `#/play` (`screens/play.js`)

### 배치 (데스크톱)
```
┌──────────────── 상단 HUD (.play-hud) ───────────────────────────┐
│ 울타리 · 쉬움              ⏱ 00:42.3          ⏳ 02:17 (타이머 선택 시) │
│ 코드 [FN-E-7K3QX9] [코드 복사]                                    │
└──────────────────────────────────────────────────────────────────┘
┌──────────────── .band-black (게임판 영역) ──────────────────────┐
│                                                                  │
│                    (게임판: 최대 560px 정사각형)                    │
│                                                                  │
│  하단 상태 줄: 울타리 「선 14개」 / 마방진 「목표 합 15」             │
└──────────────────────────────────────────────────────────────────┘
[ 처음부터 ] [ 새 게임 ] [ 💡 힌트 3 ]                  ← .btn-ghost ×3
(마방진만) 숫자 패드: [1][2][3]…[n²] [지우기]          ← 판 아래
▸ 게임 방법 (아코디언, 기본 닫힘)
```
- 모바일: HUD 2줄 → 스톱워치/타이머가 첫 줄, 게임 이름·코드가 둘째 줄. 버튼 3개는 한 줄에 균등 폭.

### HUD 문구·표시
| 요소 | 표시 |
|---|---|
| 게임 이름 | 「울타리 · 쉬움」 처럼 `{게임 이름} · {난이도 이름}` |
| 스톱워치 | 「⏱ 00:42.3」 (`분:초.1/10초`, 분은 2자리) — `aria-label="경과 시간"` |
| 타이머 | 「⏳ 02:17」 (`분:초`), 남은 10초 이하면 마젠타 + 깜빡임. 타이머 없음이면 이 요소 자체를 그리지 않음 — `aria-label="남은 시간"` |
| 코드 칩 | 코드 글자, `--fs-small`, 고정폭 숫자, 배경 `--color-surface` |
| 코드 복사 | `.btn-ghost-sm` 「코드 복사」 |
| 힌트 버튼 | 「💡 힌트 {남은 횟수}」, 0회면 「💡 힌트 0」 + 비활성 |
| 처음부터 | 「처음부터」 |
| 새 게임 | 「새 게임」 |

### 3-1. 울타리 판 (`games/fence-view.js`)
- **SVG 하나**로 그린다. `viewBox="0 0 {C*100+40} {R*100+40}"`, 바깥 여백 20.
- 구성 요소:
  | 요소 | 모양 |
  |---|---|
  | 점(꼭짓점) | 반지름 6 원, `--color-ink-soft` |
  | 숫자 단서 | 칸 가운데, 굵기 700, 크기 48(viewBox 기준), 흰색 |
  | 충족된 숫자 | `--color-ink-faint` |
  | 넘친 숫자(선이 더 많음) | `--color-magenta` |
  | 선(상태 1) | 두께 10, `stroke-linecap: round`, 흰색 |
  | ✕(상태 2) | 선 가운데 작은 ✕, 두께 4, `--color-ink-faint` |
  | 갈림길 점(선 3개 이상 만나는 점) | 점을 마젠타로, 반지름 9 |
  | 클릭 영역 | 각 변마다 투명 사각형: 가로 변 = 폭 100 × 높이 50, 세로 변 = 폭 50 × 높이 100 (변 중심 기준) |
- 클릭(또는 탭): 빈칸 → 선 → ✕ → 빈칸 순환. 오른쪽 클릭: 빈칸/선 → ✕, ✕ → 빈칸 (오른쪽 클릭 메뉴는 막음).
- 클릭 영역에 마우스를 올리면 그 변이 `--color-primary` 반투명(0.5)으로 미리 보임 (터치 기기 제외)
- `touch-action: manipulation;` (두 번 탭 확대 방지)
- 하단 상태 줄: 「선 {개수}개」

### 3-2. 마방진 판 (`games/magic-view.js`)
- **CSS Grid** + 각 칸은 `<button>`.
  ```
        c0   c1   c2
  r0  [ 2 ][   ][ 6 ] │ 8   ← 행 합
  r1  [   ][ 5 ][   ] │ 5
  r2  [ 4 ][   ][   ] │ 4
      ─────────────────
       6    5    6     ← 열 합     ↘ 대각 합(오른쪽 아래), ↙ 대각 합(왼쪽 아래)
  ```
- 칸 크기: 판 폭 ÷ n, 숫자 크기는 칸 크기의 40%, 모서리 `--radius-xs`, 칸 사이 간격 8px
  | 칸 상태 | 모양 |
  |---|---|
  | 주어진 숫자(고정) | 배경 `--color-surface-onyx`, 글자 흰색 700, 클릭해도 선택 안 됨, `aria-disabled="true"` |
  | 빈칸 | 배경 `--color-surface`, 테두리 hairline |
  | 입력한 숫자 | 배경 `--color-surface`, 글자 `--color-link` 700 |
  | 선택된 칸 | 테두리 3px `--color-primary` |
  | 중복된 숫자 | 글자·테두리 `--color-magenta` |
- 합계 칩(행 오른쪽, 열 아래, 대각선 2개는 판 오른쪽 아래·왼쪽 아래 모서리):
  | 상태 | 모양 |
  |---|---|
  | 빈칸이 남은 줄 | 현재까지 합, `--color-ink-faint` |
  | 꽉 찼고 목표와 같음 | `--color-primary` 배경 칩, 흰 글자 |
  | 꽉 찼고 목표와 다름 | 마젠타 글자 + 마젠타 테두리 |
- 숫자 패드: `1 ~ n²` 버튼 + 「지우기」. 판 아래, 한 줄 최대 9개(넘으면 줄바꿈). 이미 판에 쓴 숫자 버튼은 `opacity: 0.4` (누를 수는 있음)
- 하단 상태 줄: 「목표 합 {상수}」
- 키보드 조작은 `docs/05` 4장

### 3-3. 게임판 위 오버레이 상태
| 상태 | 판 위 표시 |
|---|---|
| 클리어 | 판이 그라디언트로 물들고 600ms 후 클리어 모달 |
| 시간 초과 | 판 위에 반투명 검정 덮개 + 「시간 초과」 글자, 조작 불가 |
| 힌트 강조 | 대상 칸/변이 마젠타로 3번 깜빡임 + 판 위 말풍선(`.hint-bubble`)에 힌트 문장 6초 표시 |

## 4. 전체 랭킹 화면 `#/ranking` (`screens/ranking.js`)

### 배치
```
전체 랭킹                                        ← --fs-display-md
가장 빨리 푼 기록 순서예요. 닉네임마다 최고 기록만 보여요.

게임   ( 울타리 ) ( 마방진 )                        ← .chip-group
난이도 ( 쉬움 ) ( 보통 ) ( 어려움 )        [ ↻ 새로고침 ] ← .btn-ghost-sm

┌─ 🥈 2위 ─┐ ┌─── 🥇 1위 ───┐ ┌─ 🥉 3위 ─┐   ← .rank-feature ×3 (1위 가운데·조금 크게)
│ 닉네임    │ │ 닉네임        │ │ 닉네임    │      모바일: 1·2·3 세로 순서
│ 01:12.4  │ │ 00:58.1      │ │ 01:20.0  │
│ 💡1      │ │              │ │          │
└──────────┘ └──────────────┘ └──────────┘
┌ 순위 │ 닉네임        │ 기록      │ 힌트 │ 날짜     ┐ ← 머리줄 --fs-small, ink-soft
│ 4    │ 퍼즐왕        │ 01:25.7  │ –    │ 11.23   │ ← .rank-row
│ 5    │ 남정_01 (나)  │ 01:31.0  │ 💡1  │ 11.23   │ ← 내 줄: 왼쪽 4px primary 띠 + 「(나)」
│ …    │               │          │      │         │
└──────────────────────────────────────────────────┘
```
- `.rank-feature`: 배경 `--color-surface`, 모서리 `--radius-lg`, 여백 16px, 순위 숫자 `--fs-display-md`. 1위만 배경 `--gradient-primary`.
- `.rank-row`: 배경 `--color-surface`, 모서리 `--radius-md`, 여백 `12px 16px`, 줄 사이 8px. 모바일에서는 「날짜」 열 숨김.
- 기록은 페널티 포함 시간. 힌트 0이면 「–」.
- 날짜 형식 `MM.DD` (한국 시간 기준).

### 문구
| 상황 | 문구 |

### 5-3. 확인 모달 (`openConfirm`)
| 버튼 | 제목 | 내용 | 확인 | 취소 |
|---|---|---|---|---|
| 처음부터 | 「처음부터 다시 할까요?」 | 「지금까지 입력한 내용과 시간이 모두 지워져요.」 | 「처음부터」 | 「계속하기」 |

- 확인 버튼은 `.btn-primary`, 취소는 `.btn-ghost`. 처음 포커스는 **취소** 버튼에.

## 7. 완료 기준
- [ ] 4개 화면 + 3개 모달이 위 배치대로 보인다
- [ ] 모든 문구가 이 문서와 글자 하나까지 같다
- [ ] 360px 폭에서 가로 스크롤이 생기지 않는다 (울타리 10×10 포함)
- [ ] 각 화면에서 초록 버튼은 최대 1개 (플레이 화면·랭킹 화면은 0개)
- [ ] 화면을 떠나면 `destroy()`가 불려 스톱워치·이벤트가 정리된다 (플레이 → 랭킹 이동 후 콘솔에 타이머 로그·에러 없음)

## 8. 검증 방법
| 확인 | 방법 | 기대 |
|---|---|---|
| 반응형 | 개발자도구 기기 모드 360 / 768 / 1280 | 겹침·잘림·가로 스크롤 없음 |
| 울타리 터치 | 모바일 모드에서 10×10 판 변 탭 | 원하는 변이 정확히 바뀜 |
| 마방진 고정 칸 | 주어진 숫자 칸 클릭 | 선택되지 않음 |
| 모달 키보드 | 확인 모달에서 Tab 반복 | 포커스가 모달 안에서만 돎, Esc로 닫힘 |
| 빈 랭킹 | DB 비운 상태에서 랭킹 화면 | 빈 상태 문구 + 버튼 |
